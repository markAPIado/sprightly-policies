# Sprightly policies

Public policy pages for **Sprightly** (`com.markapiado.sprightly`), the interval-walking app. The app's code lives in the private `sprightly` repo; this repo exists only because Google Play needs a public privacy-policy page, served free by GitHub Pages.

- Privacy Policy: `privacy/` → https://markapiado.github.io/sprightly-policies/privacy/

When Sprightly changes how it handles data, update the page and its effective date **before** the app update ships. A terms-of-service page (`terms/`) would go here too if the developer account ever becomes a trader.
